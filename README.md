# desafio-powerbi-sales-report

Relatório interativo de vendas desenvolvido no Power BI durante o Bootcamp da DIO. Inclui análise de KPIs, segmentação de dados e visualizações estratégicas.

Desafio de Projeto: Sales Report no Power BI
 Bootcamp / Curso: Data Analytics / Power BI - DIO


📌 Descrição do Projeto:
Este repositório contém o relatório interativo de vendas (Sales Report) desenvolvido no Power BI como parte do desafio prático de projeto. 

O objetivo da solução foi transformar dados operacionais de vendas em insights visuais e estratégicos para auxílio na tomada de decisão.

🛠️ Principais Recursos e Entregáveis:
- Tratamento e limpeza de dados via Power Query.
- Modelagem de dados e criação de métricas calculadas utilizando linguagem DAX.
- Painel visual dinâmico com indicadores-chave de desempenho (KPIs), filtros temporais e segmentação por categoria/região.
- Documentação completa do projeto no README do repositório.
